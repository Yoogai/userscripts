# Userscripts

## DNS → Markdown Catalog Exporter

Экспортирует товары из текущей выдачи DNS в структурированный Markdown. Выгрузка включает товары со всех страниц, текущий поиск и фильтры, цену, ссылку, рейтинг, наличие и характеристики, если они показаны в карточке.

[Установить DNS exporter](https://raw.githubusercontent.com/Yoogai/userscripts/main/dns-shop-catalog-to-markdown.user.js)

Для установки нужен Tampermonkey или Violentmonkey. Скрипт проверяет обновления по `@updateURL` и получает новые версии с GitHub.
